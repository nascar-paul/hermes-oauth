Hermes Agent

A private, single-user automation client.

Hermes Agent is a personal software tool operated by one individual for their own use. It connects to that person's own Google account to read and write their own documents, spreadsheets, calendar and mail, so that scheduled tasks can be run without manual work.

It is not a product, it is not distributed, and it has no users other than its owner. No third party can sign in to it, and no data belonging to anyone else is accessed.

What it does with Google data is described in the privacy policy.
