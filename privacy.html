Privacy Policy

Hermes Agent · last updated 3 November 2026

Hermes Agent is a private, single-user tool. It has exactly one user: its owner. This policy describes what it does with that owner's Google account data. No other person's data is collected, because no other person can use the application.

What is accessed

With the owner's explicit consent, the application requests access to the owner's own Google Drive, Google Docs, Google Sheets, Google Calendar, Google Contacts and Gmail. Access is used only to carry out tasks the owner has scheduled or requested, such as reading a document the owner wrote, saving a report the owner asked for, or checking the owner's calendar.

How data is stored

OAuth credentials are stored as files on hardware the owner controls, with file permissions restricted to the owner's account. No credentials are stored on third-party servers. Documents retrieved from Google are held only in memory or in temporary working files on the owner's own machines, and are deleted when the task completes.

How data is shared

Data is not sold, rented, or shared with advertisers. It is not used to train models. The one exception, disclosed plainly: to perform language-model tasks, the text of a document or email may be sent to the AI model provider the owner has configured, under that provider's own terms. The owner chooses that provider and can change it. No Google data is sent anywhere else.

Retention

Working files are deleted after each task. Reports the owner asked to be saved are written back to the owner's own Google Drive, where the owner controls them. Credentials persist until the owner revokes them.

Revoking access

The owner can revoke this application's access at any time at myaccount.google.com/permissions. Revocation takes effect immediately and the application stops working.

Limited Use disclosure

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
